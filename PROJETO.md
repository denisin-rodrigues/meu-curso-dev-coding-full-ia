---

## 1. Visão

**Nome de trabalho:** Curso VibeCoding Premium — Sites com Animações de Alto Nível

**Promessa central:** Ensinar qualquer pessoa a criar sites altamente premium — com animações e efeitos visuais de nível profissional — usando vibecoding: o processo completo de desenvolvimento assistido por IA usado pelo autor em 4 projetos reais.

**Diferencial:** O curso não ensina "código de animação" do zero. Ensina um **método replicável** validado em projetos reais, com os prompts, regras e bastidores de cada um.

**Público-alvo:** Pessoas entusiasmadas com sites premium que querem resultados visuais impressionantes sem dominar programação tradicional — designers, iniciantes em dev, criadores e empreendedores digitais.

---

## 2. O Método (espinha dorsal do curso)

```
1. REFERÊNCIA   → Escolher site de inspiração (Puma, Nike, editoriais premium)
2. EXTRAÇÃO     → Criar DESIGN.md com o design system da referência
3. PROMPT       → Prompts estruturados: [contexto + referência visual + regras técnicas + output esperado]
4. BUILD        → Desenvolvimento iterativo com IA (vibecoding)
5. POLISH       → Aplicar regras de animação premium (easings, durações, stagger, scroll timing)
```

## 6. Roadmap de produção

### Fase 1 — Extração (piloto com 1 projeto)
- [ ] Escolher projeto piloto (o mais impressionante visualmente)

- [ ] Transformar prompts em templates → alimentar Prompt Vault
- [ ] Documentar regras de animação implícitas → alimentar Cheatsheet

- [ ] Repetir extração nos outros 3 projetos
- [ ] Identificar a técnica-destaque de cada um (define os módulos 2-4)
