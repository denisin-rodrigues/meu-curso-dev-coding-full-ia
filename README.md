# 🚀 Curso DEV CODING FULL IA — VibeCoding Premium

Crie sites **altamente premium** — com animações e efeitos visuais de nível
profissional — usando **vibecoding**: desenvolvimento assistido por IA, com um
método replicável validado em 4 projetos reais.

> 📄 Documento-mestre do curso: [`PROJETO.md`](PROJETO.md)

## 🧭 O Método (5 etapas)

| Etapa | O que é |
|-------|---------|
| 1. **Referência** | Escolher um site de inspiração (Puma, Nike, editoriais premium) |
| 2. **Extração** | Criar um `DESIGN.md` com o design system da referência |
| 3. **Prompt** | Prompts estruturados: contexto + referência + regras técnicas + output |
| 4. **Build** | Desenvolvimento iterativo com IA |
| 5. **Polish** | Easings, durações, stagger, scroll timing |

## 🗂️ Estrutura

```
/
├── PROJETO.md            # documento-mestre (visão, método, roadmap)
├── modulos/              # módulos 01–04 do curso
├── prompt-vault/         # biblioteca de prompts (hero, scroll, design, polish)
├── cheatsheets/          # regras de animação e design premium
├── estudos-de-caso/      # os 4 projetos reais: referência → processo → resultado
└── metodo/               # checklist replicável do VibeCoding
```

## 🚦 Por onde começar

1. Leia o [`PROJETO.md`](PROJETO.md) para entender a visão e o roadmap.
2. Siga o [`metodo/checklist-vibecoding.md`](metodo/checklist-vibecoding.md) para construir seu primeiro site.
3. Use o [`prompt-vault/`](prompt-vault/) como ponto de partida dos prompts.
