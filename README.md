# 🚀 Meu Curso — Dev Coding Full IA

Repositório de estudos e projetos do curso **Dev Coding Full IA**, focado em
desenvolvimento de software potencializado por Inteligência Artificial.

## 📚 Sobre

Aqui ficam os exercícios, anotações e projetos práticos desenvolvidos ao longo
do curso. O objetivo é dominar o fluxo de desenvolvimento moderno usando
ferramentas de IA como copiloto de código, automação e agentes.
