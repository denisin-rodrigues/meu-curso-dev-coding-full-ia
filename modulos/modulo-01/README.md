# Módulo 1 — O Método Completo (carro-chefe)

Construção de **um** site premium do zero, aplicando as 5 etapas do método VibeCoding.

- **Projeto usado:** `[PREENCHER: qual dos 4 sites — o visualmente mais impressionante]`
- **Técnica-destaque:** método completo, ponta a ponta

## Aulas

1. **Referência** — escolher e dissecar o site de inspiração
2. **DESIGN.md** — extrair o design system (cores, tipografia, espaçamento, motion)
3. **Prompts** — montar os prompts estruturados (contexto + referência + regras + output)
4. **Build** — desenvolvimento iterativo com IA (vibecoding)
5. **Polish** — easings, durações, stagger, scroll timing
6. **Deploy** — publicar o site
