# Prompt Vault — Design System (DESIGN.md)

Prompts template para a etapa de **EXTRAÇÃO** — transformar uma referência visual num `DESIGN.md` estruturado.

> Estrutura de todo prompt: **[contexto + referência visual + regras técnicas + output esperado]**

---

## Template base

```
CONTEXTO:
Quero extrair o design system do site de referência para reusar no meu projeto.

REFERÊNCIA VISUAL:
[link ou screenshots do site de referência]

REGRAS TÉCNICAS:
Documente em formato DESIGN.md:
- Paleta de cores (com hex e uso)
- Tipografia (famílias, pesos, escala)
- Espaçamento e grid
- Componentes recorrentes
- Estilo de motion (durações, easings, sensação)

OUTPUT ESPERADO:
Arquivo DESIGN.md completo e reutilizável como contexto em prompts futuros.
```
