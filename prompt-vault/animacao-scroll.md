# Prompt Vault — Animação de Scroll

Prompts template para efeitos disparados/controlados pelo **scroll** (GSAP ScrollTrigger, parallax, reveal, pin).

> Estrutura de todo prompt: **[contexto + referência visual + regras técnicas + output esperado]**

---

## Template base

```
CONTEXTO:
Quero adicionar animação de scroll na seção [nome] do site.

REFERÊNCIA VISUAL:
Efeito como em [site/exemplo]. Ver DESIGN.md.

REGRAS TÉCNICAS:
- Biblioteca: GSAP + ScrollTrigger
- Gatilho: [ex: elemento entra na viewport]
- Comportamento: [ex: pin + reveal sequencial com stagger]
- Scrub: [ex: true para acompanhar o scroll]

OUTPUT ESPERADO:
Código da animação integrado à seção, com comentários.
```
